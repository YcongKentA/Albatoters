ALBATOTERS — SOUNDTRACK YOUR STORY
================================

This is an improved 60% front-end progress build of the Team Albatoters personal music vlog website.

PAGES
- index.html — Home
- mood-match.html — Interactive mood-to-artist suggestions
- artist.html — Featured artist collection with live search
- vlog.html — Music story cards with category filters
- about.html — Project information and personal listening journal
- contact.html — Validated contact form that prepares and copies a message

FUNCTIONAL FEATURES
- Shared responsive navigation across all six pages
- Mobile navigation menu
- Dark/light theme toggle saved in the browser
- Mood Match recommendations
- Artist search
- Music story category filters
- Listening journal with localStorage save and delete
- Contact form validation and copyable message
- Responsive layouts and reduced-motion support

CURRENT 60% / 100% SCOPE / LIMITATIONS
- This is a front-end project. It does not have a server, database, login, or admin dashboard.
- Journal entries are stored only in the current browser/device and can be lost if browser storage is cleared.
- Contact form prepares a message for the visitor to copy; it does not send email automatically because no team email or backend endpoint was provided.
- Artist images are the original image assets supplied in the uploaded project.
- Some story content is sample placeholder editorial content and can be replaced by the team.
